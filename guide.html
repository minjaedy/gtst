프렛노트 사용 안내

레슨 일정과 연습 과제를 선생님과 학생이 같은 화면에서 봅니다.

처음 들어갈 때

선생님과 학생이 입장하는 방법이 다릅니다.

학생

이름과 나이를 직접 등록합니다

첫 화면 학생 칸에서 학생으로 등록하기를 누르고 이름, 나이, PIN을 정하면 바로 들어갑니다. 다음부터는 목록에서 내 이름을 고르고 PIN만 입력하면 됩니다.

나이는 해가 바뀌면 자동으로 한 살 올라가니 다시 고치지 않아도 됩니다.

선생님

PIN 하나로 관리합니다

이름은 강승만 선생님으로 되어 있어 따로 입력하지 않습니다. 초기 PIN은 1234이며, 들어간 뒤 오른쪽 위 PIN 변경에서 본인만 아는 번호로 바꿔 주세요.

학생이 PIN을 잊었을 때는 학생 탭에서 그 학생의 PIN 초기화를 누르면 됩니다. 초기화된 학생은 다음 입장 때 PIN을 새로 정합니다.

학생이 PIN을 잊었다면 선생님에게 초기화를 요청하세요. 선생님 PIN은 초기값 1234에서 꼭 바꾸시고, 학생에게는 알려 주지 마세요.

스케줄

주 단위 표에서 누가 언제 오는지 봅니다.

선생님

빈 칸을 눌러 수업을 넣습니다

  • 표에서 원하는 요일·시간 칸을 누르고 학생과 수업 길이를 고릅니다.
  • 수업이 아닌 개인 일정도 같은 방식으로 넣어 시간을 막아 둘 수 있습니다.
  • 표에 보이는 시간 범위는 위쪽에서 조절합니다.
선생님

이름으로 찾습니다

스케줄 맨 위 검색창에 학생 이름을 넣으면 그 학생의 예정된 수업이 날짜순으로 모두 나옵니다. 가장 가까운 예약 주로 이동을 누르면 표가 그 주로 넘어갑니다.

학생

변경이 필요하면 요청합니다

내 수업에서 변경 요청을 누르고 사유를 적어 보냅니다. 선생님 화면 위쪽에 요청이 뜨고, 선생님이 새 시간으로 옮기거나 취소하면 표에 바로 반영됩니다.

과제

수업이 끝나면 학생이 연습할 내용을 적어 둡니다.

학생

배운 것을 과제로 올립니다

과제 탭 위쪽에 곡명, 목표일, 수업에서 배운 내용을 적어 추가합니다. 선생님도 같은 목록을 보기 때문에 다음 수업 전에 무엇을 연습 중인지 알 수 있습니다.

학생

체크리스트로 쪼갭니다

과제마다 할 일을 따로 적어 두고 하나씩 체크합니다. "1~8마디 천천히 10번"처럼 잘게 나눌수록 연습할 때 편합니다. 진행 상황은 3/5 형태로 카드 위에 표시됩니다.

학생

연습을 기록합니다

연습한 시간과 내용을 남기면 카드 아래에 날짜별로 쌓입니다. 과제 상태는 배정됨 · 연습중 · 완료 중에서 직접 바꿉니다.

앱처럼 쓰기

홈 화면에 올려 두면 주소창 없이 앱처럼 열립니다. 쓰는 기기를 고르세요.

  1. 사파리로 엽니다

    받은 주소를 사파리에 붙여 넣습니다. 크롬이나 카카오톡 안에서 열면 홈 화면 추가가 나오지 않습니다.

  2. 공유 버튼을 누릅니다

    화면 아래 가운데, 위로 향한 화살표가 있는 네모 아이콘입니다.

  3. 홈 화면에 추가를 고릅니다

    목록을 아래로 내리면 있습니다.

  4. 추가를 누릅니다

    이름은 그대로 두어도 됩니다. 홈 화면에 기타 아이콘이 생깁니다.

  1. 크롬으로 엽니다

    받은 주소를 크롬 주소창에 붙여 넣습니다.

  2. 메뉴를 엽니다

    오른쪽 위 점 세 개를 누릅니다. 아래에 설치 안내가 바로 뜨면 그것을 눌러도 됩니다.

  3. 앱 설치를 고릅니다

    홈 화면에 추가로 보이기도 합니다. 둘 다 같은 기능입니다.

  4. 설치를 누릅니다

    앱 서랍과 홈 화면에 아이콘이 생깁니다.

  1. 크롬이나 엣지로 엽니다

    받은 주소를 주소창에 붙여 넣습니다.

  2. 주소창 오른쪽 설치 아이콘을 누릅니다

    모니터에 화살표가 들어간 모양입니다. 보이지 않으면 오른쪽 위 점 세 개 → 저장 및 공유 → 페이지를 앱으로 설치를 고릅니다.

  3. 설치를 누릅니다

    바탕화면과 시작 메뉴에 아이콘이 생기고, 창 하나로 따로 열립니다.

화면이 예전 그대로라면 새로 고침을 한 번 하세요. 컴퓨터는 Ctrl+Shift+R, 맥은 Cmd+Shift+R입니다. 아이폰은 탭을 완전히 닫았다가 다시 엽니다.

알아 둘 것

  • 입력한 내용은 바로 저장되어 폰과 컴퓨터 어디서 열어도 같게 보입니다. 따로 저장 버튼은 없습니다.
  • 선생님과 학생 화면이 실시간으로 연결되어 있어, 한쪽에서 바꾸면 다른 쪽에 곧바로 나타납니다.
  • 다른 사람 계정으로 바꾸려면 오른쪽 위 사용자 전환을 누릅니다.
  • PIN은 자물쇠가 아니라 서로를 구분하기 위한 장치입니다. 주소는 필요한 사람에게만 알려 주세요.
